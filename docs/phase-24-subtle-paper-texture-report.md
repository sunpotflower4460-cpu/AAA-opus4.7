# Phase 24 Subtle Paper Texture Report

## 目的

Phase 24では、ユーザーからの具体的な指摘に基づき、背景と紙面質感を修正しました。

主な方針は以下です。

- 色を濃くしない
- 背景の直線的な格子を消す
- 和紙の繊維感と雲状の濃淡ムラだけを薄く足す
- 可読性を絶対に落とさない
- 紙片・入力面の影を短く柔らかくする
- 既存の月・余白・明朝/ゴシック分離の思想は維持する

---

## 実装内容

### 1. 背景から格子線を消す

Phase 21 / 23 で入っていた障子風・紙幅風の直線表現を、Phase 24の `body::before` / `body::after` 上書きで消しました。

背景には `repeating-linear-gradient` を使わず、以下だけで構成しています。

- 左上主光源の radial-gradient
- 一方向のごく薄い linear-gradient
- 複数の不規則な radial-gradient による雲状ムラ
- feTurbulence による繊維ノイズ

### 2. 色味を濃くしない

`body` の背景は `var(--paper-base)` を基準に戻しました。

茶色く濃くするのではなく、生成りのまま質感だけを足しています。

### 3. 繊維ノイズを控えめに追加

`body::after` に以下のSVG noiseを追加しています。

- `feTurbulence`
- `type="fractalNoise"`
- `baseFrequency="0.014"`
- `numOctaves="2"`
- `opacity: 0.04`
- `mix-blend-mode: multiply`

強度は可読性優先で、0.03〜0.05の範囲内に収めています。

### 4. 雲状の濃淡ムラ

`body::before` に複数の不規則な `radial-gradient` を重ねました。

規則的なパターンに見えないよう、中心位置と大きさをばらけさせています。

### 5. カード・入力面の物理感を抑制

前回のような強い紙束感・回転・重い影は解除し、以下へ調整しました。

- 低く柔らかい影
- 2〜5px程度の不均一角丸
- ほんの薄い紙繊維ノイズ
- 文字の可読性を保つ控えめな text-shadow

## 戻し方

Phase 24は最後に読み込まれる補正レイヤーです。

戻したい場合は `src/main.tsx` から以下を外します。

```ts
import "./phase24.css";
```

ただし、Phase 24はPhase 21/23の過剰な格子・濃さを打ち消す目的なので、現状では残すことを推奨します。

## 確認ポイント

- 背景から直線の格子が消えている
- 色が前より濃くなっていない
- 静止画で均一なベタ塗りではなく、薄い繊維と濃淡ムラがある
- 本文・タイトルの可読性が落ちていない
- カードや入力面の影が重すぎない
- FABが画面上で重くなりすぎていない
