# Phase 23 Analog Washi Report

## 目的

ユーザー提供の実機スクリーンショットを確認したうえで、残心 / Zanshin の和紙感をさらに強くしました。

スクショ上では、画面全体の設計はかなり整っていますが、まだ以下の印象が残っていました。

- 背景が綺麗すぎて、手漉き紙というより上品なUI背景に見える
- カードが紙片というより、丸みのあるUIカードに見える
- 検索欄やメモカードにガラス/デジタルUI感が残る
- 和紙の長い繊維や紙端の毛羽立ちがまだ弱い
- 文字が紙に沈む感じがもう少し欲しい

Phase 23では、機能追加ではなく、見た目と触感の方向性を「和紙風UI」から「紙片の束」へ寄せることを目的にしています。

---

## 実装方針

### 1. 紙背景ではなく、紙の場にする

背景全体に、より濃い生成り、低周波の紙むら、長い繊維、細かい斑点を追加しました。

### 2. カードを紙片にする

NoteCardに以下を追加しました。

- わずかなランダム風回転
- 紙が重なっているような下端影
- 斜め繊維
- 紙面ノイズ
- 手漉き風の不均一な外形

これにより、一覧が「UIカードのリスト」ではなく「紙片の束」に見える方向を狙っています。

### 3. 紙端の毛羽立ち

`clip-path` を使って、完全な角丸ではない紙端にしました。

対象:

- `.editor-paper`
- `.read-mode-paper`
- `.zanshin-note-card`
- `.zanshin-paper-slip`
- `.zanshin-search-bar`

### 4. 墨の沈み

タイトル・本文・カード内テキストに、微細な `text-shadow` を追加しました。

目的は立体影ではなく、ディスプレイ上の文字が紙面に少し吸われているように見せることです。

### 5. 検索欄を紙巻きに寄せる

検索欄の背景にも紙肌と影を強め、白いフォーム部品ではなく、細い紙片の上に検索が乗っているようにしました。

### 6. FABを墨玉に寄せる

黒い丸ボタンはそのまま便利ですが、UI部品感が強かったため、墨玉のような内側の陰影を追加しました。

## 注意

このPhaseはかなり攻めた質感です。

もしスクショ上で重く見える場合は、まず `--analog-washi-intensity` を `0.82` 〜 `0.9` 程度に下げるのが安全です。
