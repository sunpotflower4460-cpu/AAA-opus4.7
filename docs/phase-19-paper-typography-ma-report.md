# Phase 19 Paper / Typography / Ma Report

## 目的

Phase 19 は、残心 / Zanshin の既存思想を壊さず、紙・日本語文字組み・読み返しの余韻を磨くためのブラッシュアップです。

新しい大型機能を増やすのではなく、既存の「書く」「残る」「読み返す」を静かに深めることを目的にしました。

---

## 実装したこと

### 1. Phase 19 専用CSSレイヤー

`src/phase19.css` を追加し、既存の `src/index.css` を大きく置換せずに、上書きレイヤーとして読み込む構成にしました。

これにより、既存の紙・月・日付印・保存状態の実装を壊さず、Phase 19 の調整を独立して確認しやすくしています。

### 2. 日本語文字組みの規律

以下のクラスを追加しました。

- `.jp-text-discipline`
- `.jp-poetic-copy`
- `.jp-writing-surface`

主な意図は以下です。

- `line-break: strict` による日本語改行品質の向上
- `word-break: normal` による不自然な分割の抑制
- `overflow-wrap` による長文・長い英数字混在時の破綻回避
- `text-spacing-trim` は `@supports` 内に限定し、対応環境のみで使う

適用箇所:

- メモカードのタイトル / 本文プレビュー
- 空状態コピー
- 読み返しモード本文
- 既存エディタの入力面へのCSS側補助

### 3. 読み返し専用の縦書きモード

`src/components/ReadMode.tsx` を追加しました。

設計判断:

- 編集画面に縦書きを入れない
- 一覧から既存メモを開くと、まず読み返しモードへ入る
- 読み返しモードから `言葉を直す` で既存エディタへ移動する
- 新規メモ作成時は従来通り直接エディタへ入る

これにより、

> 書く = 横書きの実用  
> 読み返す = 縦書きの余韻

という体験の対比を作りました。

### 4. 紙質感の上書き調整

`src/phase19.css` で以下を追加しました。

- 低周波 `feTurbulence` による有機的な紙目
- 左上の月光を主光源とする補助レイヤー
- `.editor-paper` / `.paper-card` / `.zanshin-paper-slip` の微細な不均一角丸

狙いは、紙を派手に見せることではなく、均一すぎるUI感を少しだけ減らすことです。

### 5. 空状態の余白純化

`EmptyState` に `zanshin-empty-state` を追加し、空状態が説明過多にならず、余白そのものが立つようにしました。

Premium導線・チュートリアル・余計な説明は追加していません。

- 新規作成は従来通り編集画面に直接入る
- 編集 / 自動保存 / 削除 / 削除Undo / 検索 / お気に入りが壊れていない
- iPhone 375 / 390 / 430px 幅で縦書きが破綻しない
- 長文メモで横スクロールが重くない
- 紙目が汚れやノイズとして主張しすぎない
- 空状態が説明過多になっていない
