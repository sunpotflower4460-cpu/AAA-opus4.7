# Phase 21 Washi Depth Report

## 目的

Phase 21では、Phase 19で整えた紙・文字組み・読み返し体験を土台に、さらに強く「紙のような質感」と「和の空気」を高めました。

ただし、桜・鳥居・過剰な筆文字のような安易な和風モチーフは追加していません。

今回の方向性は以下です。

- 和紙の長い植物繊維
- 障子越しの光
- 紙端の不均一さ
- 薄い継ぎ目
- 墨が紙に沈むような文字の質感
- 余白がただの空白ではなく、紙面として立つ感覚

---

## 参考にした観点

### 和紙

和紙は、楮・三椏・雁皮などの植物繊維から作られる紙であり、均一な白い面ではなく、長い繊維・薄いむら・光の散り方が質感の核です。

Phase 21では、短いノイズだけでなく、斜め方向の長い繊維線と低周波の紙肌むらを追加しました。

### 障子

障子は、紙が光を柔らかく拡散し、桟の影が空間の奥行きを作ります。

Phase 21では、画面全体にごく薄い格子影を加え、直接的な模様ではなく「紙越しの気配」として扱いました。

### 間 / 余白

余白は、単に何も置かないスペースではなく、意味を運ぶ空間です。

Phase 21では、空状態や読み返しモードの背景に、紙面中央の淡い光と影を加え、何もない場所にも紙の存在感が出るようにしました。

## 実装内容

### 1. 画面全体の紙質感強化

`body` / `body::before` / `body::after` に以下を追加しました。

- 低周波の大きな紙肌むら
- 斜め方向の長い繊維線
- 細かい斑点
- 障子越しのような格子影
- 左上から入る柔らかい紙面光

外部画像は使わず、CSSの `data:image/svg+xml` とグラデーションで完結しています。

### 2. 紙片の厚みと紙端

以下の要素に対して、紙端・内側光・影を強化しました。

- `.editor-paper`
- `.paper-card`
- `.zanshin-paper-slip`
- `.paper-surface`
- `.paper-premium`

特に `.editor-paper::after` / `.paper-card::after` / `.zanshin-paper-slip::after` で、薄い紙繊維と端の厚みを足しています。

### 3. 紙の継ぎ目

`.editor-paper::before` / `.read-mode-paper::before` に、ごく薄い中央の継ぎ目を追加しました。

これは装飾線ではなく、古い紙面や継ぎ紙の気配として扱います。

### 4. 読み返しモードの紙面化

`.read-mode-paper` に、縦書きの読書感を強めるための薄い縦方向の紙幅線と紙肌ノイズを追加しました。

巻物感を強くしすぎず、「一枚の紙を横へ読んでいく」感覚に寄せています。

### 5. 文字の墨感

`.read-mode-body` / `.writing-textarea` / `.read-mode-title` / `.note-title-input` に、ごく薄い `text-shadow` を追加しました。

目的は影を見せることではなく、文字がディスプレイ上に貼り付くのではなく、紙に少し沈んで見えるようにすることです。

### 6. 空状態の紙面中央化

`.zanshin-empty-state::before` に淡い楕円の光と影を加え、空状態を単なる背景ではなく、紙面中央の余白として立たせました。
