# 綴りのブラウザ・生成物証拠

製品コードは `6d56452`。LinuxのChromium 156.0.8078.79で採取した実画面と生成物です。文章は合成データです。再現コマンドと端末確認手順は [引継ぎ](../HANDOFF.md) にあります。

- [紙肌を同じ色と墨で並べた画面](paper-comparison.png)。同じ文章で基本和紙と追加紙8種を切り替えました。
- [基本PDFの生成例](basic-sample.pdf)。無題のメモから綴じ、結合アクセント・絵文字・異体字を含む行を抽出しました。
- [操作とファイルの照合](check.py)。ChromiumとLinux版WebKitで日英の制作・JSON復元、200%相当、購入前の見本を再現します。生成器を直接呼ぶ追加試験では、縦書きA6の53頁とPNGの10面を照合します。

紙肌・PDFを取得したのはブラウザ環境です。iPhoneの撮影、VoiceOver、署名候補での出力、Appleでの購入試験は [受入記録](../ACCEPTANCE.md) に未確認として記録しています。
