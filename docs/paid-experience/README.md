## この文書群の役割

本人の言葉を、好きな紙と筆あとで整え、綴じ、読み返し、作品として手元へ残す買い切り拡張 **「残心 綴り」** の引継ぎです。既存の書く・保存する・読み返す体験を土台に、紙、書体、製本の見せ方、装丁、出力までを一つの体験として設計しています。

商品とデータの仕様は詳細設計に、現在の実装候補と確認結果は受入記録にまとめています。[詳細設計](DESIGN.md) · [受入記録](ACCEPTANCE.md)

## 商品の骨格

- 一つの非消耗型購入を想定。価格は **1,800円の仮説**、商品IDは `zanshin.tsuzuri` の案。登録済み・市場検証済みではありません。
- 紙8種、追加の筆あと4候補、全3形式の綴じ方、6仕立て、追加装丁6種、複数冊、自分の仕立て保存、画像・PDF出力を一式にします。
- 普段の入力・読み返しにも追加の紙と筆を使えます。冊子の設定とは独立させます。
- 既存の紙と筆あと4種、無料の基本一冊、基本PDF、原文取り出し、全データのバックアップ・復元、読みやすさとデータ保護を無料で提供する設計です。
- 有料素材は本人の文で何度でもプレビューできます。作成済み・復元済みの冊子や文章を購入状態で削除・閉鎖しません。
- 広告、定期課金、AI代筆、アカウント、クラウド同期は初期商品へ追加しません。

素材名・数の意味、無料一冊の例外、取消後の編集、出力範囲はDESIGNを正本にしてください。ここでの短い説明を理由に条件を省略しないでください。

## 実装の完成単位

最初の区切りはP0〜P2です。保存済みメモから基本の一冊を作り、保存・読書・全文の基本PDF・JSONバックアップと復元まで通します。その後P3〜P4で素材と三形式を揃え、P5で購入・復元・取消、P6で日英・実機・出力・掲載物を整合させます。

**商品全体はP0〜P6です。** 最初の試作を作って残りを省略したり、全8紙・4追加筆・3形式を未完成のまま販売文へ載せたりしません。フォントは具体候補を示した採用目標であり、バイナリ、権利、縦横、文字範囲、PDFを確認して確定します。
