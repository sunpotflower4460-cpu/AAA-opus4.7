| # | 内容 | 原因 | 対応 |
|---|------|------|------|
| 1 | 紙面・検索札・タグラインが**虹色のまだら**になり、タイル継ぎ目も見える | `phase28.css` の紙ノイズ画像で彩度除去（feColorMatrix）が外れ、feTurbulence の色がそのまま背景になっていた | `phase31.css` で、茶色の単色＋透明度だけが揺らぐノイズに差し替え（色を持たないので環境差でも虹色にならない） |
| 2 | お気に入りの印・背骨が金にならず**墨色** | `text-gold/82` など Tailwind 標準に無い透明度のクラスが生成されていなかった | `tailwind.config.js` に透明度ステップを追加。極小文字の `/48` `/54` `/62` は可読性のため `/80` `/72` に引き上げ |
| 3 | 検索欄が 15px で、iPhone でタップするたびに**画面が拡大** | iOS は 16px 未満の入力欄で自動ズームする | 16px に統一 |

## 追記: 筆あと（字の表情）と和紙のアナログ感

### 筆あと
- ホーム・書く画面・読み返し画面の「筆」ボタンから、**明朝 / 筆 / 墨 / 手書き**を選べる（Yuji Syuku / Yuji Boku / Klee One を同梱、OFL）。
- 適用先は書いた言葉（タイトル・本文・一覧のカード・ロゴ・詩的コピー）。ボタンなど UI の文字は読みやすさ優先で据え置き。
- 設定は `zanshin.prefs.brush.v1` に保存。メモ本体の保存キーとは完全に分離（壊れてもメモに影響しない）。描画前に反映するので字体のちらつきなし。
- 墨のにじみ（text-shadow）で、字の縁をわずかに柔らかく。

### 和紙・アナログ感（`src/phase32.css`）
- 楮の白い繊維・茶の繊維・塵を手描きした継ぎ目なしタイルを、背景（固定）と各紙片に重ねた。
- 紙片の縁を内側へ少し沈め、手漉きの厚みを出した。
- 読み返し画面の紙の隅に、朱の落款「残」を添えた（装飾のみ、タップ不可）。
