# Phase 42 — 提出前の最終ブラッシュアップ

## 修正した不具合・品質問題

| # | 内容 | 原因 | 対応 |
|---|------|------|------|
| 1 | 紙面・検索札・タグラインが**虹色のまだら**になり、タイル継ぎ目も見える | `phase28.css` の紙ノイズ画像で彩度除去（feColorMatrix）が外れ、feTurbulence の色がそのまま背景になっていた | `phase31.css` で、茶色の単色＋透明度だけが揺らぐノイズに差し替え（色を持たないので環境差でも虹色にならない） |
| 2 | お気に入りの印・背骨が金にならず**墨色** | `text-gold/82` など Tailwind 標準に無い透明度のクラスが生成されていなかった | `tailwind.config.js` に透明度ステップを追加。極小文字の `/48` `/54` `/62` は可読性のため `/80` `/72` に引き上げ |
| 3 | 検索欄が 15px で、iPhone でタップするたびに**画面が拡大** | iOS は 16px 未満の入力欄で自動ズームする | 16px に統一 |
| 4 | 入力中に**灰色の枠**が出る | `phase22.css` のフォーカスリングが入力欄に効いていた | 枠を消し、キャレットを金寄りに |
| 5 | 空状態の見出しが「ん。」だけ次行に落ちる | 自動折り返し | 行を明示（「まだ、言葉は／置かれていません。」） |
| 6 | 削除ダイアログのボタンが「残してお／く」「手放す（削／除）」と折れる | 幅不足 | `nowrap` と、ラベルを「手放す」に |
| 7 | 起動時・バウンス時に白が見える可能性 | 地色未指定 | `html` と Capacitor `ios.backgroundColor` に紙色 |
